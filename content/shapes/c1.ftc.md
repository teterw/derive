# c1.ftc

Question shapes seen in real papers and textbook exercises, and which
generator covers each. See `docs/CONTENT-PIPELINE.md` section 2.

## c1.ftc-first
- [x] A linear integrand with a plain x upper limit -> `c1.ftc-first`
- [x] A quadratic integrand -> `c1.ftc-first`
- [x] An upper limit of `x^2`, needing the chain rule -> `c1.ftc-first`
- [x] An upper limit of `kx` -> `c1.ftc-first`
- [ ] A variable *lower* limit, where a minus appears
- [ ] Both limits variable
- [ ] An integrand that cannot be integrated in closed form
- [ ] The accumulation function's own maximum

## c1.ftc-second
- [x] A linear integrand -> `c1.ftc-second`
- [x] A quadratic -> `c1.ftc-second`

- [x] A negative lower limit -> `c1.ftc-second`
- [ ] A trigonometric integrand between special angles
- [ ] An exponential integrand
- [ ] An integral needing a substitution first
- [ ] An integrand that dips below the axis, where area and integral differ

## c1.net-change
- [x] A velocity, giving displacement -> `c1.net-change`
- [x] A flow rate, giving a volume -> `c1.net-change`
- [x] A production rate, giving a total -> `c1.net-change`
- [x] A velocity that changes sign -> `c1.net-change`
- [ ] The distance travelled rather than the displacement
- [ ] An acceleration integrated twice
- [ ] A rate given as a graph rather than a formula
- [ ] Average value of a function over an interval

## c1.area-between
- [x] A line above a parabola -> `c1.area-between`
- [x] The same with a steeper parabola -> `c1.area-between`
- [x] Crossings that are not at the origin -> `c1.area-between`
- [x] A wider region -> `c1.area-between`
- [ ] Two parabolas
- [ ] Curves that cross three times, needing the integral split
- [ ] A region bounded by a curve and both axes
- [ ] Integrating with respect to y instead of x
